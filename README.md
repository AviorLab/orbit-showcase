# ORBIT

**From an approved spec to work you can inspect.**

An AI development control room by [Avior Kasay](https://github.com/AviorLab). ORBIT brings specifications, approvals, task queues, requirement changes and execution evidence into one workspace.

## Why I'm building it

Automation projects spread across tools, conversations and disconnected logs. ORBIT is my approach to keeping the intended work, its current state and the evidence of its outcome together.

## What is implemented

- A local dashboard and persistent project/task state.
- Separate specification approval and execution steps.
- Versioned requirement changes and evidence history.
- Duplicate prevention and recovery scenarios tested against simulated providers.

## Current stage

**Active development.** A local implementation exists, with automated tests for the core flow. Live provider integrations, full pilot validation and cloud deployment are still being developed and verified.

The development stack includes **Python, SQLite, JavaScript and Docker**. The integration pilot targets **Make, monday.com and FillFaster**.

This is the public project overview. The implementation repository is private.
